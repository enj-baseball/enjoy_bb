# イコノイジョイ野球部（仮）

=LOVE / ≠ME / ≒JOY が好きなメンバー向けの、東京・千葉メインのエンジョイ野球コミュニティ募集サイトです。

## サイト構成

- `index.html` — メインページ
- `css/style.css` — レスポンシブデザイン
- `js/main.js` — モバイルメニュー、募集要項コピー、共有機能
- `assets/favicon.svg` — favicon
- `robots.txt` / `sitemap.xml` — 検索エンジン向け設定
- `.github/workflows/pages.yml` — GitHub Pages デプロイ

## GitHub Pages

このリポジトリは GitHub Actions から Pages にデプロイできる構成です。

1. GitHub の `Settings`
2. `Pages`
3. `Build and deployment`
4. `Source` を `GitHub Actions` に設定
5. `main` へ push すると自動デプロイ

公開URL:

https://enj-baseball.github.io/enjoy_bb/

## 方針

- 初心者・ブランクあり歓迎
- 18歳以上（高校生不可）
- 東京・千葉メイン
- 月1〜2回程度
- 現場優先OK
- 勝敗より楽しさ優先
- ヤジ厳禁
- 費用は当日の実費を参加者で都度割り勘
- ポジションはローテーション
